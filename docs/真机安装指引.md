> 这份文档只回答一个问题：**怎么把 App 装到你自己的手机上**。
> 「编译过没过」由 CI 回答，跟这里无关。

## 0. 包在哪（本机已就绪，不用去 GitHub 下）

## 1. 装环境（只做一次）

Sideloadly 需要**网页版** iTunes 与 iCloud（**微软商店版必须先卸载**，这是它官方要求）：

| 要装的东西 | 从哪下 |
|---|---|
| iTunes（网页版） | https://www.apple.com/itunes/download/win64 |
| iCloud | https://support.apple.com/zh-cn/106330 |
| Sideloadly | https://sideloadly.io/ |

---

## 2. ⚠️ 两个必做项（漏了必报 `Invalid file`）

1. **Anisette 必须切到 `Local`**
   Sideloadly → 高级选项 → Anisette 里先点 `Download`，然后在左侧列表里**选中 `Local`**。
   **只下载不切换等于没做。** 它默认用的是官方远程服务器（要捐赠、国内常连不上），
   连不上时**签名还没开始就失败了**，而它报的**也是** `Invalid file` —— 极易误判。
2. **拖进去的必须是 `.ipa` 文件本身**（不是压缩包）。
   本机那个路径已经是解压好的 `.ipa` ✓

---

## 3. 安装步骤

1. 手机用数据线连电脑 → 手机上点「信任此电脑」
2. Sideloadly 的 `Apple ID` 填你的（**免费账号就行**）
3. 把 `EleseCattery-1506dd3-unsigned.ipa` 拖进 `IPA` 框
4. 点 **Start**，等它跑完（第一次会要 Apple ID 密码 / 双重验证码）
5. 手机上：**设置 → 通用 → VPN与设备管理 → 信任**那个开发者证书
6. 桌面出现「Elese的猫舍」

---

## 4. 免费账号的硬限制（是账号能力，不是 App 的问题）

- **7 天过期**：到期后 App 打不开。重连一次电脑、用 Sideloadly 重新签一次即可
  （它自带自动续签选项，可以打开）
- **10 个 App ID / 3 台设备**（Apple 官方限制）
- 遇到这些**不要去改代码** —— 它们跟实现无关

## 5. 装不上时怎么分锅（按高发排序）

| 现象 | 多半是什么 | 怎么办 |
|---|---|---|
| `Invalid file` | Sideloadly **读不出**手上的文件（**不是**苹果拒绝了你） | ①Anisette 切到 Local 没有 ②拖的是不是 `.ipa` ③路径别带中文/空格 ④升 Sideloadly ⑤换网络 |
| 签名过了但**启动即崩** | 包是 Debug 构建（带 `*.debug.dylib`） | 本包已验过没有 ✓；CI 里也有闸门拦这种包 |
| 装上了、桌面**图标是白的** | 图标没进包 | 本包已验过 `CFBundleIconName` ✓ |
| 提示 `application-groups` | 免费账号不支持 App Group | 本工程不用 App Group ✓ 不会遇到 |
| 一直卡在 signing | 到 Apple 服务器的网络不稳 | 换网络；或先在 iCloud 里退出账号再登一次 |

> `Guru Meditation <16进制>` 是 Sideloadly 自己的内部编号，**不是诊断信息**，
> 看它后面那句人话就行。

## 6. 装上之后怎么验（逐条：点哪里 → 看到什么 → 坏了是什么样）

> 写法说明：**光写"验一下 XX"是没法执行的**。所以每条都写成三行 ——
> 「点哪里」「应该看到什么」「如果坏了会是什么样」。
> 第三条（繁育阶段）是唯一在验**设计决定**的，最值得看。

### ① 底部导航
- **点哪里**：看着底部那排胶囊，依次点 首页 / 种猫 / 繁育 / 记账 / 更多
- **应该看到**：五个页面都进得去；被选中的那格是**实心紫色**（其余是灰图标）
- **坏了的样子**：点了没反应，或者选中态没颜色

### ② 种猫头像照片
- **点哪里**：`种猫` → 右上角紫色 **＋** → 表单最上面那块「选一张头像」
- **应该看到**：
  1. 系统相册弹出，选一张猫的照片；
  2. 左边那个 72×72 的方块里**立刻**变成你选的照片（**还没点保存就能看到**）；
  3. 填个名字（随便，比如「测试」）→ 点底部「保存档案」；
  4. 回到种猫列表 → 那一行左边是**照片**（不是首字）；点进详情页也是照片
- **坏了的样子**：那方块一直显示名字的首字（说明照片没存上）

### ③ ⭐ 繁育阶段跟着日期自动走（**这一条在验一个设计决定**）
- **点哪里**：
  1. 底部 `繁育` → 点第一条（标题是 `Mochi × Leo` 那张卡）→ 进详情
  2. 看最上面那张卡：右边有个阶段徽章，**现在应该是「怀孕」**；下面四段进度条**前两格是实心紫**
  3. 往下找到「进展」卡 → 里面有一行 **`怀孕`**，它右边的开关是**打开**的（下面显示日期）
  4. **把那个开关关掉**（就点一下开关本身）
- **应该看到**：**顶上那张卡的徽章当场从「怀孕」变成「配对」**，四段进度条从 2 格变回 1 格
  （再打开开关，又会变回「怀孕」）
- **确认保存**：点底部「保存进展」→ 返回列表 → 列表里那张卡也是「配对」
- **坏了的样子**：开关关了但徽章不动；**或者**你要在某个地方手动去"选阶段"才能改
- 🔑 **判据其实是一句话：整个 App 里你找不到任何"手动选阶段"的地方，而阶段却会跟着日期自己变。**
  如果哪天你发现要自己去选阶段，那就是推导规则坏了。

### ④ 记一笔 + 金额对上
- **点哪里**：`记账` → 右上角 **＋** → 输入金额（比如 `120`）→ 「花在哪」选**猫粮主食** →
  标题留空也行 → 点底部「记下这一笔」
- **应该看到**：回到记账页，**本月累计支出比原来多 120**；「分类占比」里"猫粮主食"也多了 120；
  「明细」里第一条是这笔
- **坏了的样子**：数字没变，或者明细里看不到

### ⑤ 本地备份（这条在验"数据真的在你手上"）
- **点哪里**：`更多` → 「设置 · 备份与导出」→ 第一行「创建本地备份」
- **应该看到**：页顶弹出一条浅紫色提示条，写着
  「备份已生成：elesecattery-backup-…….json（xx KB）」
- **再去系统「文件」App 验一次**（这是关键的一步）：
  `文件` → 浏览 → **我的 iPhone** → 应该有一个 **Elese的猫舍** 文件夹 →
  点进去能看到 `Elese备份` 文件夹，里面就是刚才那个 json
- **坏了的样子**：提示条报错；或者在「文件」App 里**找不到「Elese的猫舍」这个文件夹**
  （那就说明"数据在你手上"这条承诺没落地，是要我改的）

### ⑥ 桌面图标是不是那只猫 ✅ **已确认通过**

### ⑦ 新增一条提醒（这一版新加的）
> 之前这个模块**只能看示例数据、不能新增** —— 是我自己审出来的缺口，已补上。
> ⚠️ 要用这一条，**需要装新包**（`dist/EleseCattery-unsigned-cef7d52.ipa`）。

- **点哪里**：`繁育` 之外的任一处都行，两个入口：
  - 底部 `更多` → 「提醒通知」→ 右上角紫色 **＋**
  - 或 `种猫` → 点一只猫 → 找到 「**它的待办**」→ 点「给它加个提醒」（这样会自动带上这只猫）
- **应该看到**：
  1. 表单三块：**提醒什么**（类型可选疫苗/驱虫/称重/B超/预产期/出窝回访）→ **给谁** → **哪天到期**
  2. 「标题」**留空也行**，上面会实时显示它会用什么名字（如 `Mochi · 驱虫`）
  3. 点底部「加进待办」→ 回到列表，**新提醒出现在对应分组里**（今天/本周/已逾期）
- **再验一步（这才是关键）**：回到列表 → **长按任意一条提醒** →
  应该弹出菜单，有「改日期或说明」和「删除这条提醒」
- **坏了的样子**：点 ＋ 没反应；或者保存后列表里没有新条目；或者长按没反应

### ⑧ 提醒与本地通知联动（可选，需要开通知权限）
- **点哪里**：`更多` → 「提醒通知」→ 顶部那张卡右下的「开启提醒」
- **应该看到**：系统弹出通知授权 → 允许后卡片右侧状态变成「**已开启**」
- **说明**：到期当天上午 9:00 会响一次。**不用立刻验**（要等到那天），知道它开了就行

## 7. 已知的、这次故意没做的

- **头像只存本机**：换手机不会跟着走，所以要靠"备份 + 恢复"（设置页里那两个入口）
- **状态屏（骨架屏）**：组件写了，但本地读数据是毫秒级，**没有真实的"加载中"场景** —— 硬造一个 loading 是假的，就没接
- **没有云同步、没有账号**：这是产品决定，不是没做完
